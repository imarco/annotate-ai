annotate-ai

A self-hosted review layer for web pages. Highlight text, mark a region or pin an element, then discuss it in a thread with Markdown, emoji and images.

Comments, replies and image bytes are stored in this service's SQLite database. Each calling site uses a registered site key and origin.

Connect a site

Register the site's origin with bun server/cli.ts create-project, then paste the generated script tag into its HTML:

<script src="http://your-comment-service:18767/embed.js" data-key="SITE_KEY" defer></script>

The key is visible in browser source and identifies the site. It does not identify individual reviewers. See the repository README for setup and deployment.

Try this page

Start the service, create a project allowing this page's origin, then open /?key=SITE_KEY. Select this sentence or place a pin here; the comment will remain after refreshing.
